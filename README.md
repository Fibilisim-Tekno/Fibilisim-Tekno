## 🚀 Featured Project

### [LeanAgents](https://github.com/Fibilisim-Tekno/leanagents)

[![CI](https://img.shields.io/github/actions/workflow/status/Fibilisim-Tekno/leanagents/ci.yml?branch=main&style=flat-square&label=CI)](https://github.com/Fibilisim-Tekno/leanagents/actions/workflows/ci.yml)
![Version](https://img.shields.io/badge/version-v0.1.0--alpha.1-orange?style=flat-square)
[![License](https://img.shields.io/github/license/Fibilisim-Tekno/leanagents?style=flat-square)](https://github.com/Fibilisim-Tekno/leanagents/blob/main/LICENSE)

**Load only the expertise a coding task actually needs.**

LeanAgents routes explicit task facts, prepares selected context, runs bounded review/fix flows and records verification evidence instead of loading every role and rule for every task.

**Available now:**
- task routing and context preparation
- TypeScript reviewer and bounded fix/apply workflow
- token-budget and validation tooling
- benchmark/evaluation infrastructure
- instruction bundles for **Codex, Kiro, Cursor and Antigravity**

**Runtime status:** Codex bootstrap loading and bounded review/fix flows have been exercised with the real Codex CLI. Kiro, Cursor and Antigravity currently have format-level validation; native runtime verification is still in progress.

→ [Repository](https://github.com/Fibilisim-Tekno/leanagents) · [Benchmarks](https://github.com/Fibilisim-Tekno/leanagents/tree/main/bench) · [Adapter status](https://github.com/Fibilisim-Tekno/leanagents/blob/main/docs/ADAPTERS.md)
